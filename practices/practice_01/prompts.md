## Master Prompt v1

Соберите здесь контракт второго запуска. Не копируйте все документы целиком — ставьте ссылки на файлы и переносите только необходимый для задачи контекст.

### 1. Цель и роль

- Цель: проверка PR и поиск проблем в TRAINING_PR.diff
- Роль AI: AI Reviewer

### 2. Входы и источники

- Обязательный вход: @practices/practice_01/TRAINING_PR.diff
- Разрешённые файлы и источники: только TRAINING_PR.diff и выходные файлы context.md, prompts.md, problem.md
- Context Pack — факты, правила, примеры и ограничения: см. context.md

### 3. Задача и артефакты

- Что сделать: проанализировать TRAINING_PR.diff, найти проблемы и заполнить context.md, prompts.md, problem.md
- Что вернуть: изменения в трёх файлах согласно их форматам

### 4. Формат результата

- Структура ответа: строго соответствовать шаблонам в context.md, prompts.md, problem.md
- Ограничения объёма: не добавлять лишние разделы; не выходить за рамки фактов из diff

### 5. Полномочия и запреты

- Разрешено: читать TRAINING_PR.diff, редактировать context.md, prompts.md, problem.md
- Запрещено: использовать любые другие файлы/источники, делать предположения вне diff

### 6. Рабочий процесс и остановка

- Шаги: Прочитать diff -> проанализировать изменения и риски -> провалидировать выводы по строкам diff -> заполнить файлы
- Когда остановиться и запросить человека: если требуются данные вне TRAINING_PR.diff

### 7. Проверки и evidence

- Как проверять утверждения: каждое утверждение подтверждать ссылкой на файл и строки из diff
- Какое evidence сохранить: ссылки на строки diff в prompts.md (колонка "Как проверили")

### 8. Definition of Done

- Задача закончена, когда: три файла заполнены, все выводы подтверждены строками diff, форматы соблюдены
