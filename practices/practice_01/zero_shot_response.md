Если LLM медленный, запросы будут висеть; лучше сделать асинхронный маршрут и/или вызывать LLM неблокирующе.

     Suggested changes (минимальные)                                                                                                                                                   
                                                                                                                                                                                       
     1. Ввести Pydantic-схемы:                                                                                                                                                         
        - Request: class ReviewRequest(BaseModel): diff: str                                                                                                                           
        - Response: class ReviewResponse(BaseModel): comment: str                                                                                                                      
        - Обновить сигнатуру эндпоинта: async def create_review(payload: ReviewRequest) -> ReviewResponse.                                                                             
     2. Валидация и обработка ошибок:                                                                                                                                                  
        - Проверять, что diff непустой и не превышает лимит (например, 64–128 KB), иначе 422.                                                                                          
        - Обернуть llm.generate в try/except; на таймауты/ошибки возвращать 502/503 с понятным сообщением.                                                                             
     3. Ограничение и санитизация промпта:                                                                                                                                             
        - Тримминг/усечение diff, явные маркеры, например: "=== BEGIN DIFF === ... === END DIFF ===".                                                                                  
     4. Неблокирующая архитектура:                                                                                                                                                     
        - Сделать эндпоинт async; при наличии sync LLM — вызывать в executor (run_in_executor) либо перейти на async-клиент.   

        5. Безопасность:                                                                                                                                                                  
        - Добавить аутентификацию/авторизацию, если эндпоинт не предназначен для публичного доступа.                                                                                   
     6. Тесты:                                                                                                                                                                         
        - Юнит-тест для ReviewService.review (happy path + ошибки LLM).                                                                                                                
        - Интеграционный тест эндпоинта: валидный запрос, отсутствующий diff, слишком большой diff.
