# Tree of Thoughts

- Решение, для которого нужны альтернативы: усиление артефакта unit‑проверок из practices/practice_01/tests_unit.md (уточнение Evidence с номерами строк, добавление негативных/граничных кейсов и проверки делегирования API) с сохранением исходного формата.
- Критерии выбора: минимальность изменений и соблюдение формата; трассируемость к TRAINING_PR.diff/context.md/problem.md с номерами строк; полнота по ключевым кейсам; корректность ожиданий.

## Внешне описанные альтернативы

| Альтернатива | Плюсы | Минусы | Оценка по критериям |
|---|---|---|---|
| A | Минимальные правки исходных строк и добавление 3 новых кейсов (кратность вызова, пустой diff, делегирование) | Может не покрыть негатив при отсутствии ключа diff | 7/10 |
| B | Полное покрытие: уточнённые Evidence, новые кейсы включая негатив по ключу diff | Чуть больше изменений текста в строках таблицы | 9/10 |
| C | Только расширение Evidence без добавления новых строк | Не покрываются граничные и негативные сценарии | 5/10 |

## Выбор

- Выбранная альтернатива: B
- Почему: максимальная полнота при сохранении формата и минимальности структуры; все ожидания трассируются к TRAINING_PR.diff/context.md/problem.md с номерами строк.
- Как проверим: ручной чек Evidence по строкам файлов; в таблице каждая строка содержит точные ссылки на строки исходников.
